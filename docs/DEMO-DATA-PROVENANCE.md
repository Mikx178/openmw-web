# Demo data provenance

**Date:** 2026-07-13 · **Scope:** the demo game data baked into `openmw.data`
(the `?nomw` / "example world" experience), i.e. the contents of
`fsroot/gamedata/` at build time.

## Composition

The demo tree is assembled exclusively from freely-licensed sources:

| Content | Source | License |
|---|---|---|
| `openmw-template.omwgame`, template icons/meshes/textures | [OpenMW template](https://gitlab.com/OpenMW/template) | CC-BY 4.0 / GPLv3 |
| `ExampleSuite.omwaddon`, `Land.esp`, suite meshes/textures | [OpenMW Example Suite](https://gitlab.com/OpenMW/example-suite) | CC-BY 3.0 / CC-BY-SA 3.0 (per-asset list in `ExampleSuiteAuthors.txt`) |
| `splash/splash.dds` | Example Suite assets | CC-BY / CC-BY-SA |
| `textures/tx_masser_*.dds`, `tx_secunda_*.dds` (moon phases) | Procedurally generated by Virtastic | CC0 (public domain) |
| `meshes/xbase_anim_female.*`, `meshes/xargonian_swimkna.*` | Byte-copies (aliases) of the Example Suite's own `xBase_Anim.*` | same as Example Suite |

Attribution files (`ExampleSuiteAuthors.txt`, `LinksToLicenses.txt`,
`CREDITS-DEMO-DATA.txt`) are shipped inside the demo bundle itself.

Some suite textures were transcoded (uncompressed DDS → DXT1/DXT5 with
mipmaps) and 4096px sources downscaled to 2048px for web delivery. No
creative modifications were made.

## Audit method (2026-07-13)

1. SHA-256 manifest of every file in `fsroot/gamedata/` joined against
   manifests of the upstream Example Suite and template trees — every
   non-generated, non-transcoded file hash-matches its upstream source.
2. Every file was additionally byte-compared against the contents of retail
   `Morrowind.bsa`, `Tribunal.bsa`, and `Bloodmoon.bsa` (parsed directly).
   **Result: 0 files identical to any retail archive entry.**
3. Content plugins checked for Bethesda master dependencies: the demo loads
   only `openmw-template.omwgame` + `Land.esp` + `ExampleSuite.omwaddon`
   (see `fsroot/openmw.cfg`); no plugin depends on `Morrowind.esm`.

An earlier iteration of the demo (pre-2026-07-13) included a combat-village
showcase (`PopulateVillage.omwaddon`, `TestNPC.omwaddon`) whose creature/NPC
assets were retail-derived; that content was removed entirely and never
existed in this repository's git history (game data has always been
gitignored).

**No Bethesda / ZeniMax content is included or distributed.**
